# 🐷 Piggy's Banana Maze

A small maze game made for (and with) a 7-year-old. Help the pig find all the bananas in a dark maze.

**Play it:** https://albin-willman.github.io/pig-maze/

## How to play

- Move with the **arrow keys** / **W A S D**, the on-screen arrows, or by dragging on the maze (touch).
- The whole maze is lit up for 3 seconds at the start of each level, then only the area around the pig is visible.
- 🐮 **Cows** guard some bananas and want a password: the Swedish word for the picture they show.
- 🔐 **Treasure chests** open when you solve a math problem.
- Some bananas are **fakes** and don't count, and some passages have **invisible walls**.
- Pick a hat for the pig in the top bar.

Everything is in a single file, `index.html`, with no dependencies or build step.
